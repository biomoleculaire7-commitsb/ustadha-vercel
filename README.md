# الأستاذ المرافق الذكي — رياضيات السنة الرابعة متوسط
نسخة مستقلة للنشر على Vercel

## محتوى المجلد
- `public/index.html`: التطبيق كاملاً (63 درساً على السبورة).
- `public/audio/`: صوت الأستاذة المسجّل. يكون فارغاً حتى تشغّل سكربت الصوت.
- `public/exercises.json`: بنك التمارين. يكون فارغاً حتى تشغّل سكربت التمارين.
- `api/ask.js`: خادم «اسأل الأستاذة». اختياري، ومدفوع حسب الاستعمال.
- `scripts/`: سكربتات تشغّلها مرة واحدة على جهازك.

**بدون أي سكربت يعمل التطبيق مباشرة:** الدروس كلها على السبورة، بصوت الهاتف أو الكمبيوتر.

---

## 0) المتطلبات
- تثبيت **Node.js 18 أو أحدث** من nodejs.org.
- انسخ الملف `.env.example` باسم `.env`، ثم ضع فيه المفاتيح التي تحتاجها.

## 1) صوت الأستاذة (مجاني تقريباً، مرة واحدة)
اختر مزوّداً واحداً من الاثنين:

**Microsoft Azure (أنصح به، وفيه صوت جزائري)**
1. ادخل portal.azure.com، ثم Create resource، ثم **Speech**.
2. اختر Pricing tier: **Free F0**. يعطي نصف مليون حرف مجاناً كل شهر، والدروس كلها حوالي 75 ألف حرف.
3. من Keys and Endpoint انسخ **KEY 1** و**Location/Region**.
4. في ملف `.env` ضع:
   ```
   AZURE_SPEECH_KEY=المفتاح
   AZURE_SPEECH_REGION=westeurope
   ```

**أو Google Cloud:** فعّل Text-to-Speech API وأنشئ API key، ثم ضع `GOOGLE_TTS_KEY=...` في ملف `.env`.

**ثم في الطرفية (داخل المجلد):**
```
npm run samples
```
هذا الأمر يعرض الأصوات النسائية العربية المتاحة، ويحفظ عينة لكل صوت في المجلد `samples`.
استمع إليها، واختر الصوت الذي يعجبك، ثم شغّل الأمر مع اسمه، مثلاً:
```
npm run voice -- ar-DZ-AminaNeural
```
يولّد الأمر حوالي 1200 ملف صوتي في `public/audio`، ويأخذ بضع دقائق.
يمكن ضبط السرعة بإضافة `--rate 0.9`.

## 2) بنك التمارين (حوالي 5 إلى 10 دولارات، مرة واحدة)
1. أنشئ حساباً في console.anthropic.com، وأضف رصيداً، ثم أنشئ API key.
2. ضع في ملف `.env`:
   ```
   ANTHROPIC_API_KEY=المفتاح
   ```
3. شغّل:
   ```
   npm run exercises
   ```
   يحضّر 3 مستويات لكل درس، وفي كل مستوى 3 تمارين بحلولها، ويحفظها في `public/exercises.json`.
   إذا توقف السكربت، أعد تشغيله وسيكمل من حيث توقف.
4. **راجع الملف بنفسك قبل النشر**، وصحّح أي تمرين فيه خطأ.

لدروس محددة فقط: `npm run exercises -- --only div,pgcddef`

## 3) النشر على Vercel
**الطريقة الأسهل:**
1. ارفع المجلد إلى مستودع GitHub. الملف `.env` لا يُرفع.
2. في vercel.com: Add New، ثم Project، ثم اختر المستودع، ثم Deploy.

**أو من الطرفية:**
```
npx vercel --prod
```

ستحصل على رابط مثل `https://ustadha.vercel.app` تشاركه مع تلاميذك.

## 4) «اسأل الأستاذة» (اختياري ومدفوع حسب الاستعمال)
- **التفعيل:** في Vercel ادخل Settings، ثم Environment Variables، وأضف `ANTHROPIC_API_KEY`، ثم أعد النشر (Redeploy).
- **الحدود الافتراضية:** 15 سؤالاً في الساعة لكل تلميذ، و500 سؤال في اليوم للجميع.
- **تغيير الحدود:** عبر المتغيرين `ASK_PER_HOUR` و`ASK_PER_DAY`.
- **إذا لم تضف المفتاح:** تختفي خانة السؤال تلقائياً.

## تجربة محلية قبل النشر
```
npx serve public
```
ثم افتح الرابط الذي يظهر في الطرفية.

## ملاحظات
- **المفاتيح:** لا تضعها أبداً داخل `public`، ولا ترفع الملف `.env`.
- **تعديل نصوص الدروس:** أعد تشغيل `npm run voice -- <نفس الصوت>`. لن يولّد إلا الجمل الجديدة.
