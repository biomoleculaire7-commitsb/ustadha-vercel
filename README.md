# الأستاذ المرافق الذكي — رياضيات السنة الرابعة متوسط
نسخة مستقلة للنشر على Vercel

## محتوى المجلد
- `public/index.html`: واجهة التطبيق.
- `private/lessons.js`: محتوى الدروس الـ63. لا يصل إليه إلا تلميذ مفعَّل.
- `public/admin.html`: لوحة الأستاذ لتفعيل الحسابات.
- `api/login.js` و`api/lessons.js` و`api/admin.js`: الدخول والتفعيل.
- `public/audio/`: صوت الأستاذة المسجّل. يكون فارغاً حتى تشغّل سكربت الصوت.
- `public/exercises.json`: بنك التمارين. يكون فارغاً حتى تشغّل سكربت التمارين.
- `api/ask.js`: خادم «اسأل الأستاذة». اختياري، ومدفوع حسب الاستعمال.
- `scripts/`: سكربتات تشغّلها مرة واحدة على جهازك.

## ⭐ أولاً: حسابات التلاميذ (ضروري)
الدروس لا تظهر إلا بعد دخول التلميذ وتفعيل حسابه. اتبع هذه الخطوات مرة واحدة في Vercel:

1. **قاعدة البيانات:** في مشروعك على Vercel ادخل Storage، ثم Create Database، ثم **Upstash Redis**، واختر الخطة المجانية Free. بعدها اضغط Connect to Project.
   هكذا تُضاف المتغيرات `KV_REST_API_URL` و`KV_REST_API_TOKEN` تلقائياً.
2. **المتغيرات:** في Settings، ثم Environment Variables، أضف:
   - `AUTH_SECRET`: نص سري طويل عشوائي، 30 حرفاً على الأقل، ولا تغيّره بعد ذلك.
   - `ADMIN_PASSWORD`: كلمة سر لوحة الأستاذ.
3. **إعادة النشر:** ادخل Deployments، ثم ⋯، ثم Redeploy.

**كيف يعمل الدخول:**
- **التلميذ:** يدخل الرقم المدرسي (16 رقماً) واللقب والاسم. أول مرة يُسجَّل طلبه «في الانتظار».
- **أنت:** تفتح `https://موقعك.vercel.app/admin.html` وتدخل كلمة السر، ثم تضغط «✅ تفعيل» مع اختيار تاريخ نهاية الاشتراك، مثلاً نهاية الفصل.
- **بعد التفعيل:** يدخل التلميذ بنفس المعلومات فتظهر له الدروس.
- **طريقة أسرع:** تضيف تلاميذ قسمك مسبقاً، واحداً واحداً أو قائمة منسوخة من Excel، فيُفعَّلون مباشرة.
- **عند انتهاء التاريخ:** يُقفل الحساب تلقائياً، وتجدده بزر «🔄 تمديد».

**ملاحظة:** هذه بيانات قاصرين. اطلب موافقة الأولياء، ولا تجمع أكثر من الرقم واللقب والاسم.

## ⏳ التجربة المجانية والاشتراك
- `TRIAL_DAYS`: عدد أيام التجربة المجانية لأي تلميذ غير مسجّل، مثلاً `10`. ضع `0` أو احذف المتغير لإيقاف التجربة، فيصبح التلميذ الجديد «في الانتظار».
- `PAY_INFO`: نص يظهر للتلميذ عند انتهاء التجربة أو الاشتراك، مثل طريقة الدفع ورقم الواتساب.
- **في لوحة الأستاذ:** تلاميذ التجربة يظهرون بعلامة ⏳. وعندما يدفع التلميذ، اختر «💳 مشترك» ثم اضغط «🔄 تمديد».

## 📝 الأعمال الموجهة والاختبارات
- `private/bank.json`: حصة أعمال موجهة لكل درس من الدروس الـ66، واختبارات نهاية الفصول الثلاثة، كلها مع الحلول.
- لا تصل إلا لتلميذ مفعَّل، عبر `api/bank.js`.

## 📲 التثبيت على الهاتف
- **Android (Chrome):** يظهر زر «📲 تثبيت التطبيق» في صفحة الدخول والصفحة الرئيسية. أو من قائمة Chrome ⋮ اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **iPhone (Safari):** زر المشاركة ⬆، ثم «إضافة إلى الشاشة الرئيسية».

## 🔊 لماذا لا يوجد صوت؟
- **إذا لم تشغّل سكربت الصوت (الخطوة 1):** التطبيق يستعمل صوت الهاتف. وكثير من الهواتف ليس فيها صوت عربي مثبّت، فلا يُسمع شيء.
- **الحل الأفضل:** شغّل سكربت الصوت، ثم أعد النشر، فيسمع الجميع نفس صوت الأستاذة.
- **للتأكد:** افتح `https://موقعك.vercel.app/audio/manifest.json`. إذا ظهرت صفحة خطأ، فالصوت لم يُرفع.
- **حل مؤقت على Android:** الإعدادات، ثم تحويل النص إلى كلام، ثم محرك Google، ثم تثبيت بيانات اللغة العربية.

## 0) المتطلبات
- تثبيت **Node.js 18 أو أحدث** من nodejs.org.
- انسخ الملف `.env.example` باسم `.env`، ثم ضع فيه المفاتيح التي تحتاجها.

## 1) صوت الأستاذة (مجاني تقريباً، مرة واحدة)
اختر مزوّداً واحداً من الاثنين:

**Microsoft Azure (أنصح به، وفيه صوت جزائري)**
1. ادخل portal.azure.com، ثم Create resource، ثم **Speech**.
2. اختر Pricing tier: **Free F0**. يعطي نصف مليون حرف مجاناً كل شهر، والدروس كلها حوالي 75 ألف حرف.
3. من Keys and Endpoint انسخ **KEY 1** و**Location/Region**.
4. في ملف `.env` ضع:
   ```
   AZURE_SPEECH_KEY=المفتاح
   AZURE_SPEECH_REGION=westeurope
   ```

**أو Google Cloud:** فعّل Text-to-Speech API وأنشئ API key، ثم ضع `GOOGLE_TTS_KEY=...` في ملف `.env`.

**ثم في الطرفية (داخل المجلد):**
```
npm run samples
```
هذا الأمر يعرض الأصوات النسائية العربية المتاحة، ويحفظ عينة لكل صوت في المجلد `samples`.
استمع إليها، واختر الصوت الذي يعجبك، ثم شغّل الأمر مع اسمه، مثلاً:
```
npm run voice -- ar-DZ-AminaNeural
```
يولّد الأمر حوالي 1200 ملف صوتي في `public/audio`، ويأخذ بضع دقائق.
يمكن ضبط السرعة بإضافة `--rate 0.9`.

## 2) بنك التمارين (حوالي 5 إلى 10 دولارات، مرة واحدة)
1. أنشئ حساباً في console.anthropic.com، وأضف رصيداً، ثم أنشئ API key.
2. ضع في ملف `.env`:
   ```
   ANTHROPIC_API_KEY=المفتاح
   ```
3. شغّل:
   ```
   npm run exercises
   ```
   يحضّر 3 مستويات لكل درس، وفي كل مستوى 3 تمارين بحلولها، ويحفظها في `public/exercises.json`.
   إذا توقف السكربت، أعد تشغيله وسيكمل من حيث توقف.
4. **راجع الملف بنفسك قبل النشر**، وصحّح أي تمرين فيه خطأ.

لدروس محددة فقط: `npm run exercises -- --only div,pgcddef`

## 3) النشر على Vercel
**الطريقة الأسهل:**
1. ارفع المجلد إلى مستودع GitHub. الملف `.env` لا يُرفع.
2. في vercel.com: Add New، ثم Project، ثم اختر المستودع، ثم Deploy.

**أو من الطرفية:**
```
npx vercel --prod
```

ستحصل على رابط مثل `https://ustadha.vercel.app` تشاركه مع تلاميذك.

## 4) «اسأل الأستاذة» (اختياري ومدفوع حسب الاستعمال)
- **التفعيل:** في Vercel ادخل Settings، ثم Environment Variables، وأضف `ANTHROPIC_API_KEY`، ثم أعد النشر (Redeploy).
- **الحدود الافتراضية:** 15 سؤالاً في الساعة لكل تلميذ، و500 سؤال في اليوم للجميع.
- **تغيير الحدود:** عبر المتغيرين `ASK_PER_HOUR` و`ASK_PER_DAY`.
- **إذا لم تضف المفتاح:** تختفي خانة السؤال تلقائياً.

## تجربة محلية قبل النشر
```
npx serve public
```
ثم افتح الرابط الذي يظهر في الطرفية.

## ملاحظات
- **المفاتيح:** لا تضعها أبداً داخل `public`، ولا ترفع الملف `.env`.
- **تعديل نصوص الدروس:** أعد تشغيل `npm run voice -- <نفس الصوت>`. لن يولّد إلا الجمل الجديدة.
